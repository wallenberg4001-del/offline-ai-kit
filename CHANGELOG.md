# Changelog

## 1.6.0 (2026-11-24)

- One copy of every book: no second Mac copy, saves about 300 GB.
- Requires library programs built with libzim 9.6.0 or newer.
- Uninstall now removes the kit from this computer only; your drive is never changed. Deleting things from the drive is in Drive tools.
- New Drawer-ready setup: everything for Mac, Windows and Linux is on the drive and checked; no internet needed to use it.
- Before v1.6.0, Uninstall deleted the kit folder from the drive.

## 1.5.0 (2026-11-24)

- Mac Erase now hands the request to `prepare-disk.sh` through a real file. A refusal shows up in the installer log instead of an empty log.
