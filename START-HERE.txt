==============================================================
            OFFLINE AI KIT  -  START HERE
==============================================================

This puts a helpful "ask me anything" assistant and a big
library (including all of Wikipedia) on your computer, so they
still work when the internet or power is out.

Open the folder called   Click these
The folders inside are numbered. Start with the one called
   1 Install - guided
It opens a page in your web browser and explains every choice
before anything is downloaded. Pick the file for your computer
(Windows, Mac, or Linux).

If you would rather not answer any questions, open
   2 Install - no questions
instead.

FOLDER-GUIDE.txt explains every other folder.


------------------ WHICH ONE DO I NEED? ---------------------

 There is ONE file to double-click. Pick your computer:

   Windows PC ....................  EASY-INSTALL (Windows)
   Mac with an Apple chip ........  EASY-INSTALL (Mac)
   Older Mac with an Intel chip ..  EASY-INSTALL (Mac)
                                    (the same file - it can
                                     tell which Mac you have)
   Linux .........................  EASY-INSTALL (Linux).sh
                                    In a terminal:
                                    bash "EASY-INSTALL (Linux).sh"

 Not sure which Mac you have?
   Click the Apple menu (top-left corner), then
   About This Mac.
     "Chip: Apple M1" (or M2, M3, M4, M5) = Apple chip
     "Processor: ... Intel ..."           = Intel Mac

 Not sure if you have a PC?
   If your computer runs Windows, it is a PC.

 TWO WAYS TO INSTALL:

   EASY-INSTALL ...  no questions at all. Picks good choices
                     for your computer. Best for most people.

   SETUP ..........  a step-by-step "Setup Wizard" where you
   (SETUP.bat,       choose your features first: AI size,
    SETUP-MAC, or    full Wikipedia yes/no, extra libraries,
    SETUP-LINUX.sh)  sharing with phones on home Wi-Fi,
                     and optional offline maps.
                     Press Enter to take each suggestion.
                     Nothing downloads until you say yes at
                     the end. Easy Install does not ask
                     about maps and does not download them.

 On an Intel Mac the assistant is slower. An answer can take
 half a minute or more. That is normal. The library is fast.


-------------------- ON A WINDOWS PC ------------------------

 1.  Plug the computer into the wall and connect to the internet.

 2.  Double-click the file called   EASY-INSTALL (Windows)

 3.  If a blue box says "Windows protected your PC":
        click  More info   then click  Run anyway

 4.  A black window opens and shows lots of writing.
     That is normal. You do NOT need to type anything.
     Just wait.  This takes 1 to 3 hours.

 5.  When it is finished, your web browser opens by itself
     with the chat page and the library.

 6.  Next time, just double-click  "Offline AI"  on your Desktop.


----------------------- ON A MAC ----------------------------
           (Apple chip or Intel - the steps are the same)

 1.  Plug the Mac into the wall and connect to the internet.

 2.  Double-click the file called   EASY-INSTALL (Mac)

 3.  If the Mac says it "cannot be opened" or is from an
     "unidentified developer":
        click  Done  (or  OK),  then open the Apple menu
        > System Settings > Privacy & Security,
        scroll down and click  Open Anyway,  then  Open.

     (Or: hold the Control key, click the file, choose  Open,
      then click  Open  again.)

 4.  A window with writing opens. That is normal.
     If it asks to use your "Desktop folder", click  Allow.
     Just wait.  This takes 1 to 3 hours.

 5.  When it is finished, your web browser opens by itself.

 6.  Next time, just double-click  "Offline AI"  on your Desktop.

 The Mac needs macOS 13 (Ventura) or newer for the assistant.
 On macOS 12 (Monterey) you get the library only.


------------------- WHAT TO EXPECT --------------------------

 *  After it is set up, the internet is NOT needed.

 *  The first time it starts, it keeps downloading the whole
    of Wikipedia quietly in the background. This can take
    from an hour to a day or two. Leave the computer plugged
    in and switched on. Everything else works while it
    downloads.

 *  If your computer does not have much free space, the kit
    skips Wikipedia and tells you. Everything else still works.

 *  Type your question in the box at the bottom of the chat
    page and click  Ask.

 *  The chat looks up the answer in the library first. The
    numbers like [1] [2] show which library article each part
    came from - click one to read it. If the library has
    nothing on it, the chat says so and offers an answer from
    the AI's own memory instead (that one is marked as NOT
    from the library). To switch this off, untick
    "Ask the library" at the top of the chat page.

 *  The assistant can be WRONG. For medicine or first aid,
    also look it up in the library, and call 911 when you can.


--------------- PHONES, EXTRAS AND UPDATES ------------------

 Double-click STATUS (STATUS.bat on a PC, STATUS-MAC on a
 Mac). It shows what is running, then offers a little menu:

   1) Share on Wi-Fi ON/OFF - lets phones and tablets on your
      HOME Wi-Fi use the chat and library. The chat page then
      shows a QR code: point the phone's camera at it.
      ONLY at home on Wi-Fi you trust. NEVER on public Wi-Fi
      (cafes, hotels, airports). It is OFF unless you turn it
      on.

   2) Add Extra Libraries - a dictionary, free old books,
      question-and-answer sites (home repair, cooking, car
      repair, outdoors), emergency preparedness guides.
      Type the numbers you want. Needs internet to download.

   3) Add offline maps - Vancouver Island, British Columbia,
      Alberta and Saskatchewan are inside the one Canada map
      (about 10 GB). Picking those, or Canada, downloads that
      file once. Other regions are separate files. Easy
      Install does not download maps. Phones on home Wi-Fi
      open them from the chat address. Needs internet to
      download.

   4) Check for updates - only when you ask, needs internet.
      It never downloads or changes anything by itself.
      The chat page has a "Check for updates" button too.


---------------- RUNNING FROM A USB DRIVE -------------------

 Put the whole kit folder on one USB drive to use it on
 Windows, Mac and Linux. Format the drive as exFAT, NTFS
 or APFS. FAT32 cannot hold a file over 4 GB, and the kit
 will refuse the big downloads on a FAT32 drive.

 Plug it in and run START from that drive. On Windows, if
 the drive letter changes, run START from the USB again.
 START rewrites the Desktop shortcut.

 To use ONE drive on every computer, run SETUP (not Easy
 Install) and choose "All computers (universal drive)".
 That downloads the programs for Windows, Mac (Apple chip
 and Intel) and Linux (64-bit PC and ARM). The library,
 models and maps are stored once. The summary shows the
 extra disk space before anything downloads (about 11.5 GB
 more on Windows, about 13 GB more on a Mac or Linux).

 START picks the matching programs by itself
 (runtime/windows-x64, runtime/mac-arm64, runtime/mac-x64,
 runtime/linux-x64 or runtime/linux-arm64). If this
 computer's programs are not on the drive, START says so
 and tells you to run SETUP while you have internet.

 On a Mac or Linux, if the drive will not run programs
 (common on exFAT), start with bash and the file name, for
 example:

   bash "/Volumes/YOURDRIVE/offline-ai-kit/START-OFFLINE-AI-MAC.command"
   bash "/media/you/YOURDRIVE/offline-ai-kit/START-OFFLINE-AI-LINUX.sh"

 The kit then copies Kiwix and Ollama to a cache on the
 computer and runs them from there. The library stays on
 the USB.

 On a Mac, kiwix-serve cannot open a library file bigger
 than 4 GB when that file sits on exFAT. Windows and Linux
 can. Keep big files on APFS or the internal disk if you
 use a Mac. Smaller files on the USB still open.

 The computer is kept awake during long downloads. Leave
 it plugged in.


-------------------- IF SOMETHING GOES WRONG ----------------

 *  Turn the computer off and on again, then double-click
    "Offline AI" on the Desktop.

 *  If the install stopped part way, double-click the same
    EASY-INSTALL file again. It carries on where it stopped.

 *  Ask the person who gave you this kit for help.
